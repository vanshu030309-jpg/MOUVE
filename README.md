# 🎬 MOUVE

> AI-powered movie discovery and personalized recommendation platform.

MOUVE is a modern movie discovery experience designed to help users find films based on their interests, moods, genres, directors, cast, languages, themes, and viewing history.

It combines natural-language search, AI-powered recommendations, personalized discovery, and a rich movie catalog into one cinematic interface.

---

## ✨ Features

- 🤖 **MOUVE AI** — Natural-language movie recommendations based on mood, themes, genres, directors, actors, and complex preferences.
- 🎯 **Personalized Recommendations** — Recommendations adapt to your Watchlist, Favorites, and Viewing History.
- 🔎 **Smart Search** — Search by title, director, cast, genre, language, themes, and keywords.
- 🎭 **Advanced Discovery** — Explore movies through genres, moods, directors, languages, ratings, and release periods.
- 🇮🇳 **Indian Cinema Collection** — Discover selected Hindi, Telugu, Tamil, Malayalam, Kannada, Bengali, and other Indian films.
- 🎞️ **Movie Details** — Explore ratings, genres, cast, directors, languages, themes, release information, and related movies.
- ❤️ **Favorites & Watchlist** — Save movies for later with persistent local storage.
- 🕐 **Recently Viewed** — Keep track of movies you've explored and quickly rediscover them.
- 🎬 **Movie Trailers** — Watch trailers directly from movie details.
- 🔗 **Because You Watched** — Discover movies similar to films you've already enjoyed.
- 📱 **Responsive Design** — Optimized for mobile, tablet, and desktop screens.
- ♿ **Accessible UI** — Keyboard navigation, focus states, semantic controls, and accessible interactions.

---

## 🧠 AI Recommendation System

MOUVE understands natural-language movie requests such as:

- `dark sci-fi movies`
- `thrillers but not horror`
- `movies like Inception but more emotional`
- `movies directed by Christopher Nolan`
- `Indian movies with strong female characters`
- `something funny and lighthearted`
- `movies similar to my favorites`

The recommendation system considers multiple signals including:

- Genres
- Themes
- Mood
- Directors
- Cast
- Language
- Release period
- Ratings
- User preferences
- Watchlist
- Favorites
- Viewing history

Recommendations are grounded in MOUVE's movie catalog rather than inventing unavailable titles.
